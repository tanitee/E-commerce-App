# E-commerce-App

View here: https://style-m.vercel.app/

This project is a front-end e-commerce application built to simulate the core experience of an online shopping platform. It focuses on user interaction, product browsing, and cart management without relying on a backend service.

## Overview

The app allows users to explore a collection of products, view detailed information about each item, and add products to a cart for checkout. It is designed to demonstrate how a typical e-commerce interface works, including navigation between pages and managing application state on the client side.

## Features

* **Home Page**
  A landing page that introduces the platform and highlights available products.

* **Products Page**
  Displays a list of products with:

  * Pagination for easy navigation through multiple items
  * Filtering options to refine product selection

* **Product Details View**
  When a product is selected, a detailed page is shown with:

  * Product description
  * Price information
  * Quantity selection
  * Add to cart functionality

* **Cart Page**
  Shows all selected items with:

  * Product summary
  * Quantity adjustments
  * Checkout option
